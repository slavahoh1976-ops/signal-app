## Скачать

| Компьютер | Файл |
|---|---|
| **Mac с Intel** (macOS 10.14 Mojave и новее) | `Signal-Mac-Intel.zip` |
| **Mac на M1/M2/M3** | `Signal-Mac-AppleSilicon.zip` |
| **Windows 10/11** — установка | `Signal-Windows-Setup.exe` |
| **Windows** — без установки (переносная) | `Signal-Windows-Portable.exe` |
| Всё сразу + веб-версия + исходники | `Signal-…-all.zip` |

**Mac:** распакуйте zip, перетащите «Сигнал» в «Программы». Первый запуск: правый клик по приложению → «Открыть» → «Открыть» (приложение не подписано в Apple — так нужно только один раз).

**Windows:** если появится синее окно SmartScreen — «Подробнее» → «Выполнить в любом случае».

**Обновления** приходят сами: при запуске программа проверяет сайт, скачивает новую версию и предлагает перезапуститься. Схемы и библиотека сохраняются.
